# MyFabmesh.AI

**Turn a sentence or a picture into a game-ready 3D model — textured, rigged and animated.**

This repository only hosts the public website of MyFabmesh.AI (landing page, compatibility checker, privacy policy and terms of use).
MyFabmesh.AI is proprietary software: **its source code is not published here.**

## Get MyFabmesh.AI

- **Windows app** — [Microsoft Store](https://apps.microsoft.com/detail/9PH6GT8XKQDW)
- **In your browser** — [web app](https://myfabmesh.pages.dev/), nothing to install
- **Will it run on my PC?** — [compatibility checker](https://myfabmesh.github.io/MyFabmesh/check.html)

## What it does

1. **Image** — describe what you want, or start from your own picture.
2. **3D model** — a textured mesh built from that image.
3. **Rig** — a skeleton fitted automatically, for humans, animals and creatures.
4. **Animation** — walk, run, attack and more, ready to export to Blender, Unreal Engine or Unity.
